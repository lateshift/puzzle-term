On macOS, Cmd+C is performable copy (selection arrives in M8). Readline's Alt+B/F/D shortcuts need Option as Alt: `keyboard.optionAsAlt = "left"` keeps right Option for layout characters. On Windows, Ctrl+C without a selection reaches the application as `0x03`. The web uses the user's OS table and reports browser-reserved shortcuts.

For `keyboard.optionAsAlt` in Chromium, `navigator.keyboard.getLayoutMap()` supplies the exact unmodified character. Safari and Firefox lack that API: on non-US layouts, Option-as-Alt follows physical US key positions (for example German Z/Y). Chords are always encoded; no map is learned from earlier typing. The default `none` uses native layout text and needs no map in any browser.
