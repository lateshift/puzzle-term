# Native font dependencies

D-37 and the user’s 2026-10-04 continuation approve these dependencies for `puzzle-desktop` only. Dependency lint and M11 acceptance reject either in the wasm tree.

- `png = 0.18.1` (MIT OR Apache-2.0) decodes bounded embedded sbix/CBDT PNGs. `puzzle-text` receives a decoder trait and remains codec-free.
- `fontique = 0.11.1` (Apache-2.0 OR MIT) discovers installed fonts and supplies bytes. The [crates.io dependency metadata](https://crates.io/api/v1/crates/fontique/0.11.1/dependencies) requires `read-fonts ^0.41.0`. An official release recheck found no newer non-yanked stable version using 0.43. The user accepts this desktop-only duplicate because fontique’s types never enter our font parsing or shaping; those bytes are parsed by our own skrifa.
- `skrifa 0.46.2` and `harfrust 0.13.0` remain aligned on `read-fonts 0.43.3`. Neither is downgraded to accommodate fontique.

Desktop release binary before fontique: **7,147,760 bytes**, including the M11.5 PNG path. After fontique and the adapter/probes: **7,299,280 bytes**, a **151,520-byte (+2.120%)** increase. The approved COLRv1 test font remains tests/goldens only and never ships.

## Shared X11 named-colour data (M18.1)

User-approved 2026-10-11 (R4): the 782-entry X.Org MIT/X11 table, no new crate.
All OSC colour sequences share its allocation-free parser. The static sorted
lookup is generated by `tools/generate-x11-colours.py`; source, complete licence
and hashes are retained in [assets/colors](../assets/colors/README.md). No
startup work or runtime-generated map. Native/wasm build deltas are recorded
in [M18 evidence](evidence/M18.md).

## Native compositor colour space (M18.surface-colour)

User-approved 2026-10-11 (R4): `objc2-core-graphics = 0.3.2`, macOS-only
`puzzle-sys` dependency, defaults disabled, features `std` and `CGColorSpace`.
Generated bindings create and read the named sRGB profile after wgpu configure;
there is no handwritten CoreGraphics FFI. The exact version already resolves
through wgpu; no new versions/downloads or wasm dependency change. The existing
notices list its Zlib OR Apache-2.0 OR MIT licence. Native size/build observations
are retained in [M18 evidence](evidence/M18.md#m18surface-colour-explicit-layer-srgb-follow-up).

## Native MIME clipboard and paste capabilities (M18.3)

User-approved 2026-10-11 (R4): `getrandom = 0.3.4` in puzzle-embed generates
32-byte OS-random paste credentials for every native host. It is absent from
the core and wasm. `objc2-app-kit = 0.3.2`, macOS-only in puzzle-desktop, has
defaults disabled and only std/NSPasteboard enabled for safe clipboard revision
and type queries. Both exact versions already existed in Cargo.lock.

`arboard = 3.6.1` image-data is enabled only in puzzle-desktop. Upstream disables
image's defaults and selects native PNG/TIFF codecs. The app handles its own
MIME clipboard through the C callback; no arboard codecs enter puzzle-embed,
puzzle-ffi or wasm. Size/build observations are in the M18 evidence.

## Isolated coverage-guided fuzzing (M19.2b)

User approval 2026-10-13 (R4): cargo-fuzz 0.13.2, libfuzzer-sys 0.4.13 and
arbitrary 1.4.2, only in the unpublished separate `fuzz/` workspace and local
tool installation. Fuzzing uses nightly-2026-08-14, ASan and debug invariants.

M19.3 separately implements the approved hmac 0.12.1 / sha2 0.10.9 family.

## IOSurface native presentation (M12.layer)

User-approved 2026-10-17 (R4), macOS-only in puzzle-sys, defaults disabled:
objc2 =0.6.4 (std), objc2-io-surface =0.3.2 (IOSurfaceRef/CoreFoundation),
objc2-metal =0.3.2 (device, texture, command queue/buffer),
objc2-core-foundation =0.3.2 (property dictionaries/numbers/strings), and
block2 =0.6.2 (GPU completion handler). QuartzCore's existing dependency enables
CATransaction for atomic main-thread contents changes. The handler only publishes
ready ownership and wakes; it never touches Session or blocks. All versions were
already locked through wgpu. No new versions or wasm dependency are added.
Native binary/build delta is recorded once in [M12 evidence](evidence/M12.md).
