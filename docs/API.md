# Browser API (M8)

Puzzle ships a browser terminal engine and no backend. The form in `web/` connects only to an explicitly launched local development bridge. Fonts and font packs are separate assets.

The declarations generated by wasm-bindgen include the interfaces in [terminal.d.ts](../crates/puzzle-web/types/terminal.d.ts). The full settings, contents and middleware API arrives in M10.

```js
const terminal = await PuzzleTerminal.create(container, {
  settings: { font: { size: 14 } },
});
const data = terminal.onData(bytes => host.write(bytes));
await terminal.write(applicationOutput);
```

| API | Contract |
|---|---|
| `isSupported()` | Resolves `{webgpu, reason?}` without allocating a terminal. |
| `create(container, options?)` | Mounts one canvas and one textarea; shares the page device and matching font context. Fixed `cols` and `rows` must be supplied together. |
| `dispose()` | Idempotently removes listeners, closes transports, rejects pending writes and releases resources. |
| `write(string \| Uint8Array)` | Output only. Resolves when that accepted prefix is parsed and replies have been flushed. Preserves split UTF-8/VT sequences. |
| `writeln(string)` | The same output guarantee, appending CR LF. |
| `pendingBytes` | Accepted output still awaiting parsing; excludes unsent input. |
| `onData(callback)` | Encoded keys, paste and parser replies immediately in FIFO order. Returns `{dispose()}`. |
| `input(string)` | Committed input through typed API-origin policy, without local echo. |
| `paste(string)` | Core sanitization and negotiated bracketed-paste markers. |
| `sendKey(spec)` | W3C `key`/optional `code`, `ctrl`/`alt`/`shift`/`meta` and `type: press/repeat/release`. Releases emit only under kitty flag 2. |
| `focus()`, `blur()`, `hasFocus` | Native textarea focus, shared by IME, paste and keyboard handling. |
| `attachTransport({write, resize?, close?})` | Callback integration, e.g. Electron/node-pty. Methods retain their object `this`; returned disposal closes that incarnation only. |
| `connect(url, {protocol?})` | `raw` (default) or `puzzle-bridge-v1`; returns `{disconnect()}`. The host supplies the backend. |
| `exited({code?, signal?})` | Report only after final output. The notice waits for queued output; web defaults to holding the screen. |
| `cols`, `rows` | Current VT grid dimensions, excluding scrollback. |
| `fit()` | Reflows to the container's physical pixel geometry. |
| `resize(cols, rows)` | Validated explicit grid size; opts out of fitting until `fit()`. |
| `on(event, callback)` | `title`, `bell`, `resize`, `focus`, `blur`, `error`, `scroll`, `selectionChange`, `searchRequested`; returns `{dispose()}`. Errors carry a stable `code`. |

Callbacks run outside a mutable core borrow and may reenter or dispose the terminal. Reentrant input stays behind the effect being delivered. Rendering occurs only in rAF; parsing, replies and input continue when the page is hidden.

Program replies share a completion-based 4-MiB admission lane. For
`attachTransport`, `write(bytes)` may return `void` for synchronous consumption
or a `Promise<void>` resolved only after the actual writer consumes that FIFO
operation. Enqueueing is not completion. A blocked writer pauses subsequent
application output at the ordered boundary while keys, frames and disposal stay
serviceable. Reject on write failure and close the transport; never acknowledge
discarded bytes. `onData` remains an observation callback. Bridge replies return
credit only through actual PTY-write acknowledgements. A raw socket observes
the browser send-buffer drain; its remote host must enforce PTY backpressure.

## Page memory

All terminals on a page share one wasm instance and its 4 GiB wasm32 address
space. With each terminal's full 32 MiB scrollback cap, roughly 125 terminals
fit per page; other engine allocations reduce the available space. A retained
terminal probe exhausted memory during `write()` at 160 terminals with partially
filled histories (about 26 MB per terminal), not at a browser canvas limit.
Running out of wasm memory traps the whole module rather than returning an
error. Dispose unused terminals and lower `scrollback.lines` or
`scrollback.maxBytes` when retaining many sessions. Browser canvas resource
refusal separately rejects `create()` with a `WebGpuUnavailable` error.

## Local development

Run `cargo xtask web serve` and `cargo xtask bridge` in separate terminals. Open `http://127.0.0.1:8080` and paste the private URL printed by the bridge into **Connect to bridge**. Do not publish the URL. Disconnect reaps the child; reconnect creates a new terminal Session.

Bridge input is sent only within `0x84` credit. The unsent tail of a paste stays ahead of later keys and replies; ACK/resize controls bypass that queue. Output ACKs are issued after each accumulated 64 KiB actually parsed, rather than on packet receipt.

Safari/Firefox lack Chromium's `navigator.keyboard.getLayoutMap()`: configured Option-as-Alt follows US physical positions on non-US layouts (German Z/Y). The default `keyboard.optionAsAlt = "none"` uses native layout text in every browser.

Run `cargo xtask web test` for headless Chrome API/DOM/device tests and an authenticated real-bridge connection. M7 Chrome/IME review is confirmed; Safari testing is waived. M8 Chrome scrolling, selection, copy and search review remains pending.

## Selection, search and scrolling

`terminal.selection` exposes `range` (undefined when empty) and `text`. Ranges use
inclusive cells: `{start: {lineId, col}, end: {lineId, col}, block?}`. Line IDs are
exact nonnegative JavaScript integers. `select(range, mode?)` accepts `simple`,
`word`, `line`, `block` or `semantic`; a range with `block: true` defaults to block.
`selectAll()`, `selectLine(lineId)`, `selectZoneOutput(zoneId)` and `clear()` share
the Rust selection model. Zone IDs are monotonically assigned to OSC 133 command
cycles, retained through reflow, and never reused on reset; their buffer listing
arrives in M10. Unknown or evicted identities leave the selection unchanged.

```js
const selection = terminal.selection;
selection.select({ start: { lineId, col: 0 }, end: { lineId, col: 4 } });
console.log(selection.text);
selection.clear();
```

`terminal.search.find(query, {caseSensitive?})` starts literal search with smart
case when the option is omitted. It returns live read-only `SearchState` getters:
`count`, `current` (zero-based, undefined without a current hit), and `complete`.
Keep that handle and read it after refreshes; search advances at most 2,000
physical rows per frame, caps results at 10,000 and follows new output. `next()`
and `prev()` return the same live state shape and centre the selected occurrence.
`clear()` stops the query and removes fills/markers. A state always describes the
terminal's active query, including a replacement or clear. Regex is deferred.

```js
const search = terminal.search;
const state = search.find("error");
// In your UI refresh callback: show state.count and state.complete.
search.next();
search.clear();
```

`scrollLines(n)` and `scrollPages(n)` use signed counts (negative means older);
a page is rows−1. `scrollToTop()`, `scrollToBottom()`,
`scrollToLine(lineId, 'top' | 'center')` (default center), and
`scrollToPrompt(delta)` clamp to retained history. Alternate screens have none.
The `scroll` event carries `{offsetPx}` above the live tail; `selectionChange`
carries the expanded Range or undefined, and `searchRequested` has no payload:
the page focuses its own search field. Each subscription is independently disposable.

Wheel defaults are prevented only for tracking, alternate-scroll, or a local
view that can move in that direction. Pixel/line/page units retain their shared
Rust routing; Shift always chooses local history. Captured left-pointer gestures
select, double-click expands a word, triple-click a wrapped logical line,
Alt+drag selects a block and Shift+click extends. Dragging beyond an edge scrolls.
One-finger touch scrolls locally with finite momentum; reduced motion suppresses
momentum and a tap focuses the input. Touch selection/mobile UX remains deferred.
Copy runs inside keydown's user activation; HTML copy carries both text/html and
text/plain. Facades and progress handles throw `Disposed` after terminal disposal.
Wasm-bindgen handles offer `free()` for early release; dispose the terminal first
when removing it, and free retained facade/progress wrappers when no longer needed.
