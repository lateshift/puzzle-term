# Bundled fonts

These are the approved D-6 font assets used for the M2 CPU specimen and later terminal rendering. The files were extracted unchanged from the official release archives; only the two JetBrains variable font filenames were shortened for shell use.

| `SymbolsNerdFontMono-Regular.ttf` | [Nerd Fonts v3.5.1](https://github.com/ryanoasis/nerd-fonts/releases/tag/v3.5.1), `NerdFontsSymbolsOnly.zip` | `fe471e538392f51910faab985fa8e192a39dd3426125edd15b71b3680df0e749` |
